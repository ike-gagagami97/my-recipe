## 1. ひとことで言うと（必須）

保存済みのレシピを、タイトル・所要時間・日時で絞り込み／並び替えしながら一覧で確認できる。

## 2. だれの・どんな場面か（必須）

| 項目 | 内容 |
| --- | --- |
| だれ | 自分用にレシピを溜めたい個人 |
| ユーザー課題 | メモやスクショに散らばって、「今夜何作ろう」のときに候補を一覧できない |
| 提供価値 | アプリを開けばレシピのタイトルが一覧でき、キーワード検索や所要時間の絞り込みで献立の候補をすぐ把握できる |
| 使う場面 | 献立を考えるとき、買い物前に「家にあるレシピ」をざっと見たいとき、時間のないときに短時間レシピを絞り込みたいとき |

## 3. できること（必須）

- レシピ一覧画面を開く（`/recipes`）
- 各レシピのタイトル・所要時間・更新日時を一覧で見る
- レシピが0件のとき、空であることが分かる
- タイトルのフリーワード（部分一致）で絞り込む
- 所要時間をプルダウン（10分未満 / 10〜20分 / 20〜30分 / 30分以上）で絞り込む（選択即時反映、ボタンなし）
- キーワード検索と所要時間絞り込みを同時に適用できる
- 所要時間・更新日時の列ヘッダーをクリックして昇順／降順を切り替えられる
- 1ページあたり10件表示し、ページ番号付きページネーションで移動できる
- 検索・絞り込み・ソートを変更したとき、自動的に1ページ目に戻る

## 4. やらないこと（必須）

- レシピの追加（[#6](https://github.com/ike-gagagami97/my-recipe/issues/6)）・編集・削除（[#7](https://github.com/ike-gagagami97/my-recipe/issues/7)）
- レシピ詳細画面の実装（[`recipe-detail.md`](./recipe-detail.md) / [#5](https://github.com/ike-gagagami97/my-recipe/issues/5) で実施。一覧のタイトルを詳細へのリンクにする変更もそちらのスコープ）
- 画像・サムネイル表示
- タイトル以外のフィールド（本文など）のキーワード検索
- カテゴリ・タグ・食材など、所要時間以外の絞り込み軸

## 5. 操作の流れ（必須・Gherkin）

```gherkin
Feature: レシピ一覧
  保存済みのレシピを検索・絞り込み・並び替えしながら一覧で見られる

  Scenario: レシピがあるとき一覧に表示される
    Given レシピが1件以上保存されている
    When レシピ一覧画面を開く
    Then 各レシピのタイトル・所要時間・更新日時が一覧に見える
    And デフォルトで更新日時の新しい順に並んでいる

  Scenario: レシピが0件のとき空の案内が出る
    Given レシピが1件もない
    When レシピ一覧画面を開く
    Then まだレシピがないことが分かる案内が見える
    And レシピの行は出ない

  Scenario: タイトルのキーワードで絞り込める
    Given レシピが複数件保存されている
    When タイトル検索欄にキーワードを入力し、検索ボタンを押す
    Then タイトルにそのキーワードを含むレシピのみ表示される
    And マッチしないレシピは表示されない

  Scenario: キーワード検索で0件になる
    Given 入力したキーワードにマッチするレシピが存在しない
    When タイトル検索欄にそのキーワードを入力し、検索ボタンを押す
    Then 検索結果が0件であることが分かる案内が見える

  Scenario: 所要時間プルダウンで絞り込める（即時反映）
    Given 所要時間が異なるレシピが複数件保存されている
    When 所要時間プルダウンで「10分未満」を選ぶ
    Then ボタンを押さずに所要時間が10分未満のレシピのみ表示される

  Scenario: キーワード検索と所要時間絞り込みを同時に使える
    Given 所要時間が異なる・タイトルも異なるレシピが複数件保存されている
    When タイトル検索欄にキーワードを入力して検索ボタンを押す
    And 所要時間プルダウンで「10分未満」を選ぶ
    Then キーワードに一致 かつ 所要時間が10分未満のレシピのみ表示される

  Scenario: 絞り込み中にキーワード検索を追加できる
    Given 所要時間プルダウンで「10分未満」が選択されている
    When タイトル検索欄にキーワードを入力して検索ボタンを押す
    Then キーワードに一致 かつ 所要時間が10分未満のレシピのみ表示される

  Scenario: 所要時間の列ヘッダーをクリックしてソートできる
    Given レシピが複数件保存されている
    And 初期表示（更新日時の新しい順）のままである
    When 所要時間の列ヘッダーをクリックする
    Then 所要時間が短い順にレシピが並ぶ
    And もう一度クリックすると長い順に切り替わる
    And 所要時間が未設定のレシピは、どちらの向きでも末尾に表示される

  Scenario: 更新日時の列ヘッダーをクリックしてソートできる
    Given レシピが複数件保存されている
    And 初期表示（更新日時の新しい順）のままである
    When 更新日時の列ヘッダーをクリックする
    Then 古いものが上に並ぶ
    And もう一度クリックすると新しい順に切り替わる

  Scenario: 11件以上あるときページ番号付きページネーションが表示される
    Given レシピが11件以上保存されている
    When レシピ一覧画面を開く
    Then 1ページ目に10件のレシピが表示される
    And ページ番号が表示される

  Scenario: ページ番号をクリックしてページを移動できる
    Given レシピが11件以上保存されており、1ページ目を表示している
    When ページ番号「2」をクリックする
    Then 2ページ目のレシピが表示される

  Scenario: 検索条件を変えると1ページ目に戻る
    Given 2ページ目を表示している
    When タイトル検索欄にキーワードを入力して検索ボタンを押す
    Then 検索結果の1ページ目が表示される
```

## 6. 受け入れ条件（必須）

### 合格条件

- [ ] §5 の各 Scenario を Preview またはローカルで確認した
- [ ] 各レシピにタイトル・所要時間・更新日時が表示される（**日本時間（JST）**。今年は `MM/DD HH:mm`、昨年以前は `YYYY/MM/DD HH:mm`）
- [ ] 何も操作していない初期表示で、更新日時が新しいレシピが上に並ぶ
- [ ] レシピが1件もないユーザーで開くと「まだレシピがありません」の案内が出て、レシピの行は出ない
- [ ] タイトル検索欄にキーワードを入力して検索ボタンを押すと部分一致で絞り込まれる（入力中はリアルタイムで変化しない）
- [ ] 所要時間プルダウン（10分未満 / 10〜20分 / 20〜30分 / 30分以上）を選択すると即時絞り込まれる（ボタン不要）
- [ ] キーワード検索と所要時間絞り込みを同時に適用できる（どちらの順で操作しても AND 条件で機能する）
- [ ] 1ページあたり10件表示され、11件以上のときページ番号付きページネーションが表示される
- [ ] ページ番号をクリックして該当ページに移動できる
- [ ] 検索・絞り込みで11件以上に絞られたとき、1ページ目に10件表示され、ページ番号「2」で絞り込み条件を保ったまま残りが表示される
- [ ] 初期表示から所要時間の列ヘッダーを1回クリックすると短い順、もう1回で長い順に並ぶ
- [ ] 初期表示から更新日時の列ヘッダーを1回クリックすると古い順、もう1回で新しい順に並ぶ
- [ ] 所要時間が未設定のレシピはソート時に末尾に表示される（昇順・降順とも）
- [ ] 検索・絞り込み・ソートを変更したとき1ページ目に戻る
- [ ] 検索・絞り込み結果が0件のとき「条件に一致するレシピがありません」の案内が出て、検索欄と所要時間プルダウンはそのまま操作できる
- [ ] ログイン済みユーザーの自分のレシピのみ表示される（他ユーザーのレシピは見えない）

## 7. 空・エラー・例外（任意）

| 場面 | 期待する見え方・挙動 |
| --- | --- |
| レシピ0件 | 「まだレシピがありません」などの案内文。追加ボタンは出さない（追加は別 feature） |
| 検索・絞り込み結果0件 | 「条件に一致するレシピがありません」など。一覧が消えて壊れた見た目にはしない |
| 一覧の取得に失敗 | エラーメッセージを表示（真っ白・無限ロードにしない） |
| 未ログイン | ログイン画面へリダイレクト（既存の認証フローに委ねる） |
| 所要時間が未設定のレシピ | 所要時間欄は「-」などで表示。所要時間絞り込みでは非表示（対象外）とする |

## 付録（任意・空欄のままでよい）

### 実装メモ（エージェント用）

- ルート: `/recipes`（既存の `src/app/recipes/page.tsx` を活用）
- DB テーブル: `public.recipes`
  - `id` uuid PK
  - `user_id` uuid FK → `auth.users(id)` ON DELETE CASCADE
  - `title` text NOT NULL
  - `cooking_time_minutes` integer NULL（分単位。未設定可）
  - `created_at` timestamptz NOT NULL DEFAULT now()
  - `updated_at` timestamptz NOT NULL DEFAULT now()（更新時トリガーで自動更新）
  - RLS: `auth.uid() = user_id` で自分のレシピのみ参照可
  - GRANT: `authenticated` ロールのみ（anon は不可）
- 検索: タイトルの `ilike '%keyword%'`（大小文字無視）
- 絞り込み: `cooking_time_minutes` の範囲条件（NULL は対象外）
- ソート: `cooking_time_minutes ASC/DESC` または `updated_at ASC/DESC`
- ページネーション: 10件/ページ、ページ番号付き、URL クエリパラメータ（`?page=2` など）で管理
- ソート: 列ヘッダークリックで昇順／降順を切り替え。所要時間 NULL は末尾（`NULLS LAST`）
- 検索・絞り込み・ソート変更時はページを1にリセット
- 使う skills: `recipe-feature`, `supabase-migration`, `verify-frontend-change`
