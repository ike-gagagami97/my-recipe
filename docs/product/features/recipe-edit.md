## 1. ひとことで言うと（必須）

保存済みのレシピをフォームで直し、保存すると詳細に反映される。

## 2. だれの・どんな場面か（必須）

| 項目 | 内容 |
| --- | --- |
| だれ | 自分用にレシピを溜めたい個人 |
| ユーザー課題 | 材料の分量や手順を後から直したいのに、一度保存したレシピを画面から修正できない。間違えたまま残るか、別メモに書くことになる |
| 提供価値 | 詳細から編集画面を開き、既存の内容を直して保存できる。直し終わった内容がすぐ詳細に反映される |
| 使う場面 | 実際に作ってみて分量や手順を直すとき、タイトルや所要時間の誤りに気づいたとき、メモを追記するとき |

## 3. できること（必須）

- レシピ詳細から「編集」で編集画面（`/recipes/[id]/edit`）を開ける
- ログイン済みで自分の存在するレシピの編集 URL を直接開いても、編集画面が開き既存の内容が入っている
- 編集画面を開くと、そのレシピの既存のタイトル・所要時間・材料・手順・メモがフォームに入っている
- 項目を直して保存すると、そのレシピが更新される
- 保存後は、そのレシピの詳細画面が開き、直した内容が見える
- タイトルが空のまま保存しようとすると、エラーが出て保存されない
- 所要時間・材料・手順・メモは空のまま保存できる（追加と同じ）
- 「キャンセル」でそのレシピの詳細に戻れる（保存はされない）
- 未ログインで編集画面を直接開くとログイン画面にリダイレクトされる
- 他ユーザーのレシピや存在しないレシピの編集 URL を開くと、見つからない旨の画面になる（内容は見えない）

## 4. やらないこと（必須）

- 編集画面からの削除（削除は詳細のみ。[`recipe-delete.md`](./recipe-delete.md)）
- 新規追加フォームの変更（[#6](https://github.com/ike-gagagami97/my-recipe/issues/6) は完了済み。編集は別画面）
- 画像アップロード（vision 非スコープ）
- タグ・カテゴリ管理
- 下書き・自動保存・途中保存・変更の差分表示
- 一括編集
- 一覧行からの直接編集（編集は詳細の「編集」のみ）
- 材料・手順の構造化（分量を別カラムにする等）。改行区切りの複数行テキストのまま（追加・詳細と同方針）
- 他ユーザーへの共有・公開設定
- サインアップ画面（既存どおり Dashboard 手動作成）

## 7. 空・エラー・例外（任意）

| 場面 | 期待する見え方・挙動 |
| --- | --- |
| タイトル未入力・空白のみ | 保存されない。タイトルが必要だと分かるエラー。入力済みの他項目は消えない。DB は変わらない |
| 所要時間が不正（負数・小数・文字・0） | 保存されない。編集画面に所要時間の直し方が分かるエラー。入力済みの他項目は消えない。未入力（空）だけが「未設定」として許可される |
| 保存に失敗（通信・DB エラー） | 編集画面にエラーメッセージ。真っ白・無限ロードにしない。入力内容はできるだけ残す |
| 未ログイン | ログイン画面へリダイレクト（既存の認証フローに委ねる） |
| 他ユーザー・存在しない・不正 ID | 詳細と同じ「レシピが見つかりません」画面。一覧に戻るリンクを置く |
| 材料・手順の空行 | 保存は可。詳細表示では空行を除いて整列する（詳細と同方針） |
