| TC-01 | TCND-01 | | 1. … | | | L2 |

ルール:

- 期待結果は**画面上で観察できること**だけ（SQL / ログのみの判定は不可）
- §5 Scenario を包含するケースには、対応 Scenario 名を手順またはメモに書く
- 実装の内部構造（コンポーネント名・ファイルパス）を前提にしない
- データ要件が同じなら §6 にまとめて参照してよい
